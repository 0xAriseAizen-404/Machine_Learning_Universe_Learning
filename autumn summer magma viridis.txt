| Plot layout | Typical figsize |
| ----------- | --------------- |
| 1 × 1       | (8, 5)          |
| 1 × 2       | (12, 5)         |
| 1 × 3       | (18, 5)         |
| 2 × 2       | (12, 8)         |
| 2 x 3       | (18, 10)        |
| 3 × 3       | (15, 12)        |

fig, axes = plt.subplots(1, 3, figsize=(18, 5))
18 inches / 3 plots = 6 inches per plot

fig, axes = plt.subplots(2, 2, figsize=(12, 8))
12/2 = 6 inches width
8/2 = 4 inches height

The actual pixel size depends on the DPI (dots per inch):
pixels = figsize × dpi
For example, default DPI ≈ 100:
figsize=(30, 7)
30 × 7 inches → 3000 × 700 pixels
